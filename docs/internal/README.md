# Architecture Decision Records (ADRs)

The *why* behind non-obvious design choices, one decision per file.

Today the full record lives in [`../DECISIONS.md`](../DECISIONS.md) as a single numbered log. It is
being split into focused ADRs here (ROADMAP milestone M3). Until that migration is complete,
`DECISIONS.md` remains authoritative.

**Format** (once split): `NNNN-short-title.md`, each with — Context, Decision, Consequences.
Reference them from code comments as `docs/internal/NNNN-...md`.
